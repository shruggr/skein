# Backlog

The backlog is GitHub issues: https://github.com/shruggr/skein/issues. Start
at the tracker, issue #31: decisions, conventions, questions open for David
and what is ready to build. Each issue's body is the design record for its
item, and an issue closes when its work is merged to `main`. The docs in
this directory describe what is built; where they and an issue disagree,
the issue is right. Older raw notes are in `OPEN.md`.
