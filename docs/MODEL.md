# The skein model (v1), historical

This file described the 2026-09 v1 model (threads of blocks woken by a
TypeScript scheduler, with runners for the model, the shell and the
person), agreed on 2026-09-24. That code is gone: the kernel is
`kernel-zig`, and the machine is described in `VM.md` and `ARCH.md`. It is
kept only so older references resolve; the full text is in git history
(`git log -- docs/MODEL.md`).
